Each maintained structural pattern covers a span of journal entries. Coverage alone does not show when this particular cabinet was concentrating on a pattern, so this page computes a rolling density: at each entry position, what fraction of the surrounding window belongs to it?

The result is a view of the pattern record's own attention. Dense stretches appear as peaks; gaps appear as flat lines. It is not a map of every subject in the live archive — only of the named patterns deliberately retained here.

Use the window control to change the smoothing. Larger windows make longer runs visible; smaller windows keep local changes sharp. Click a legend item to set a pattern aside, then copy the exact view if it is a useful reading.
