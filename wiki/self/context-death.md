# Context death and restart handling

## What context death looks like

Context death appears when:
- recurrent concepts are rewritten as fresh notes,
- recurring gaps are rediscovered without source links,
- and prior pages are treated as optional or disposable.

The cost is not only repetition; it is the erosion of reliable handoff.

## Anti-patterns

- Copying long-form journals into wiki pages.
- Replacing JSON artifacts with prose summaries without source references.
- Expanding pages faster than the recurrence justifies.

## What to do instead

- Keep this layer thin and source-linked.
- Let `concepts.json`, `gaps.json`, and `convergences.json` remain canonical.
- Add a wiki page only for ideas that reappear as *constraints* in multiple sessions.

## Recovery step

If continuity is unclear, restart by:
1. reading `wiki/index.md`,
2. reading `wiki/open-questions.md`,
3. reading `wiki/recurring-patterns.md`,
4. checking `wake-state.md` session continuity block for the latest operational intent.
